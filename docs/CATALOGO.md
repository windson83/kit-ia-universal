# Catálogo

| Identificador | Capacidade |
|---|---|
| product-analyst | Converte pedidos de produto em requisitos, critérios de aceite e decisões pendentes. |
| arquiteto-de-software | Define arquitetura, ADRs, contratos entre componentes e planos de migração. |
| backend-dev | Implementa APIs, regras de negócio, autorização e integrações de servidor. |
| database-admin | Modela dados e revisa migrations, integridade e consultas lentas. |
| frontend-dev | Implementa interfaces e fluxos acessíveis integrados a APIs e ao design system. |
| qa-tester | Planeja e executa testes de comportamento e reproduz falhas com evidências. |
| security-auditor | Audita autorização, entradas, sessões, dependências e exposição de dados em aplicações. |
| code-reviewer | Revisa diffs e PRs buscando regressões concretas e riscos de manutenção. |
| debugger | Investiga causa raiz de erros e aplica correções com reprodução e verificação. |
| devops-engineer | Configura infraestrutura e operação, release, observabilidade e recuperação. |
| ci-cd-specialist | Cria e depura pipelines com permissões mínimas e validação de release. |
| git-workflow-specialist | Organiza commits e PRs e resolve conflitos preservando trabalho local. |
| docker-container-specialist | Cria e revisa Dockerfiles e Compose com builds reproduzíveis e operação verificável. |
| infra-security-specialist | Audita IAM, rede, pipelines, containers, IaC e recuperação de infraestrutura. |
| tech-writer | Produz guias de instalação, referência de API e runbooks fiéis à implementação. |
| ui-design-specialist | Define direção visual, tokens e fluxos preservando a identidade do produto. |
| frontmd | Projeta e implementa interfaces completas com identidade, responsividade e acessibilidade. |
| orquestramd | Coordena tarefas com dependências e capacidades disponíveis, em execução individual ou com agentes. |
| contratos-publicos-analise | Analisa e redige documentos de contratações públicas brasileiras com fontes rastreáveis. |

Aliases históricos: `architect` → `arquiteto-de-software`; `desenvolvedor-back-end` → `backend-dev`; `frontend-design_Lovable` → `frontmd`; `OrquestraMD` → `orquestramd`. Evite instalar aliases juntos para não duplicar a descoberta.
